# Introduction a Python

Depot regroupant les travaux pratiques du cours d'Introduction a Python.

Chaque TP est range dans son propre dossier avec son code source, ses donnees eventuelles, son enonce et un README dedie.

## TPs

| TP | Sujet | Dossier |
| --- | --- | --- |
| TP1 | Filtrage de numeros de telephone | `tp1-filtage-spam/` |
| TP2 | Chiffrement par substitution monoalphabetique | `tp2-chiffrement-substitution/` |
| TP3 | Random Number Generator | `tp3-random-number-generator/` |
| TP4 | Nombres premiers et images | `tp4-nombres-premiers-et-images/` |

## Recuperer le projet

```bash
git clone https://github.com/birane-m/intro-python3.git
cd intro-python3
```

## Prerequis

La plupart des TPs utilisent Python 3. Certains exercices peuvent demander des bibliotheques supplementaires indiquees dans le README du TP concerne.

Verifier Python:

```bash
python3 --version
```

Sur Windows:

```bash
py -3 --version
```

## Organisation

```text
intro-python3/
├── tp1-filtage-spam/
├── tp2-chiffrement-substitution/
├── tp3-random-number-generator/
├── tp4-nombres-premiers-et-images/
└── README.md
```

Pour executer un TP, entrer dans son dossier puis suivre les commandes indiquees dans son README.
